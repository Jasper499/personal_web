# 信息架构

## Tab 栏结构

```
┌─────────┬─────────┬─────────┬─────────┐
│  首页   │  分类   │  购物车 │  我的   │
└─────────┴─────────┴─────────┴─────────┘
```

## 页面层级

```
小程序
├── 首页 [Tab]
│   ├── 商品详情
│   ├── 搜索页
│   └── 活动专题（P2）
├── 分类 [Tab]
│   └── 商品详情
├── 购物车 [Tab]
│   └── 结算页
│       └── 地址选择/编辑
├── 我的 [Tab]
│   ├── 订单列表
│   │   └── 订单详情
│   ├── 地址管理
│   │   └── 地址编辑
│   ├── 联系客服
│   └── 隐私协议
└── 全局
    ├── 登录授权
    └── 支付结果
```

## 商家后台结构

```
管理后台
├── 登录
├── 仪表盘（订单概览）
├── 商品管理
│   ├── 商品列表
│   └── 商品编辑
├── 分类管理
├── 订单管理
│   └── 订单详情
└── Banner 管理
```

## 导航规则

| 场景 | 导航方式 |
|------|----------|
| Tab 页切换 | `wx.switchTab` |
| 进入详情 | `wx.navigateTo` |
| 结算/支付完成 | `wx.redirectTo` 或 `wx.navigateBack` |
| 购物车角标 | 全局事件更新 tabBar badge |

## 数据流

```
用户操作 → 小程序页面 → API 请求 → 后端服务 → 数据库
                ↑                              ↓
              本地缓存 ←──── JSON 响应 ←────────┘
```
