# 产品需求文档（PRD）- 匠心小铺 MVP

**版本**：v1.0  
**状态**：已评审  
**适用范围**：用户端小程序 + 商家管理后台

---

## 1. 产品概述

匠心小铺小程序为用户提供商品浏览、加购、下单、支付、订单查询能力；商家通过 Web 管理后台完成商品上架与订单履约。

## 2. 用户角色

| 角色 | 描述 |
|------|------|
| 消费者（C 端） | 浏览商品、下单、支付、查看订单 |
| 商家管理员（B 端） | 管理商品、处理订单、查看基础数据 |

## 3. 功能清单

### 3.1 用户端（P0）

#### F-001 微信登录

- **描述**：用户进入小程序自动完成微信静默登录，获取 openid
- **验收标准**：
  - 首次进入弹出隐私协议确认
  - 登录成功后本地缓存 token
  - token 过期自动刷新

#### F-002 首页

- **描述**：展示 Banner、分类入口、推荐商品
- **验收标准**：
  - Banner 支持后台配置，最多 5 张
  - 推荐商品按销量排序，展示 6-10 个
  - 下拉刷新

#### F-003 分类与商品列表

- **描述**：左侧一级分类，右侧商品列表
- **验收标准**：
  - 切换分类实时加载对应商品
  - 商品卡片展示图、名、价、销量
  - 支持上拉加载更多

#### F-004 商品详情

- **描述**：展示商品图文、价格、库存、规格
- **验收标准**：
  - 轮播图支持多图
  - 有 SKU 时弹出规格选择器
  - 「加入购物车」「立即购买」按钮可用

#### F-005 购物车

- **描述**：管理已加购商品
- **验收标准**：
  - 勾选/全选、改数量、删除
  - 失效商品（下架/无库存）置灰
  - 底部显示合计金额与结算按钮

#### F-006 下单结算

- **描述**：确认商品、配送方式、金额后提交订单
- **验收标准**：
  - 支持「到店自提」与「快递配送」
  - 快递需选择收货地址
  - 展示商品金额、运费、实付金额

#### F-007 微信支付

- **描述**：调起微信支付完成付款
- **验收标准**：
  - 支付成功跳转订单详情
  - 支付失败/取消可重新支付
  - 服务端回调更新订单状态

#### F-008 订单列表与详情

- **描述**：按状态查看历史订单
- **验收标准**：
  - Tab：全部 / 待付款 / 待发货 / 待收货 / 已完成
  - 待付款订单可取消、可支付
  - 详情展示商品、金额、物流/自提信息

#### F-009 个人中心

- **描述**：用户信息入口与功能导航
- **验收标准**：
  - 展示头像昵称
  - 订单快捷入口
  - 地址管理、联系客服、关于我们

### 3.2 商家后台（P0）

#### F-101 管理员登录

- 账号密码登录，JWT 鉴权

#### F-102 商品管理

- 商品列表、新增/编辑/上下架、图片上传

#### F-103 订单管理

- 订单列表、按状态筛选、发货（填快递单号）、完成自提

#### F-104 分类管理

- 分类 CRUD、排序

#### F-105 Banner 管理

- Banner 图片、跳转链接、排序

### 3.3 P1 功能（第二版）

- 收货地址 CRUD
- 商品搜索
- 订单评价
- 优惠券

## 4. 非功能需求

| 类型 | 要求 |
|------|------|
| 性能 | 首屏加载 < 2s（4G 网络） |
| 安全 | 接口 JWT 鉴权、支付服务端验签 |
| 兼容 | iOS / Android 微信最新两个大版本 |
| 可用性 | 核心流程 3 步内完成下单 |

## 5. 订单状态机

```
待付款(pending) --支付成功--> 待发货(paid)
待付款 --超时/取消--> 已取消(cancelled)
待发货 --商家发货--> 待收货(shipped)
待发货 --自提核销--> 已完成(completed)
待收货 --确认收货--> 已完成(completed)
```
