# 小程序账号与支付资质申请指南

本文档为**操作手册**，需你本人在微信官方平台完成注册。代码仓库已预留相关环境变量配置位。

---

## 1. 注册微信小程序账号

### 步骤

1. 访问 [微信公众平台](https://mp.weixin.qq.com/)
2. 点击「立即注册」→ 选择「小程序」
3. 选择主体类型：
   - **企业**：功能最全，推荐
   - **个体工商户**：可接入微信支付，适合小商铺
   - **个人**：免费但**无法接入微信支付**，仅适合展示型 Demo
4. 填写邮箱、密码完成注册
5. 登录后完成主体信息登记

### 获取开发凭证

路径：开发 → 开发管理 → 开发设置

| 凭证 | 用途 | 配置位置 |
|------|------|----------|
| AppID | 小程序唯一标识 | `backend/.env` → `WX_APPID` |
| AppSecret | 服务端换取 openid | `backend/.env` → `WX_SECRET` |

### 配置服务器域名

路径：开发 → 开发管理 → 开发设置 → 服务器域名

上线前需配置：
- **request 合法域名**：`https://api.yourdomain.com`
- **uploadFile 合法域名**：对象存储域名
- 开发阶段可在微信开发者工具勾选「不校验合法域名」

## 2. 微信认证（建议）

| 项目 | 说明 |
|------|------|
| 费用 | 300 元/年（企业/个体户） |
| 路径 | 设置 → 微信认证 |
| 作用 | 解锁微信支付、更高 API 配额、搜索权重 |

---

## 3. 申请微信支付商户号

### 前提

- 企业或**个体工商户**主体
- 已完成微信认证（建议）
- 有营业执照、法人身份证、结算银行账户

### 步骤

1. 访问 [微信支付商户平台](https://pay.weixin.qq.com/)
2. 注册商户号，提交经营资料
3. 审核通过后获取：
   - 商户号（mchid）
   - API 密钥（V3 密钥）
   - API 证书

### 绑定小程序

路径：微信支付商户平台 → 产品中心 → AppID 账号管理 → 关联小程序 AppID

### 配置到项目

```env
WX_MCH_ID=你的商户号
WX_PAY_KEY=你的APIv3密钥
WX_PAY_NOTIFY_URL=https://api.yourdomain.com/api/pay/notify
```

---

## 4. 小程序类目设置

路径：设置 → 基本设置 → 服务类目

匠心小铺（实体零售）建议选择：
- **商家自营 → 百货**
- 或根据实际品类选择对应类目

### 所需资质（示例）

- 营业执照
- 部分品类需经营许可证

---

## 5. ICP 备案

若使用自有服务器域名：

1. 在腾讯云/阿里云购买域名
2. 完成 ICP 备案（约 7-20 个工作日）
3. 配置 HTTPS 证书

**简化方案**：开发阶段使用本地 API；生产可用微信云托管减少备案复杂度。

---

## 6. 隐私合规

微信审核要求：

1. 在小程序后台配置《用户隐私保护指引》
2. 代码中实现隐私协议弹窗（已实现：`pages/legal/privacy`）
3. 声明收集的用户信息：openid、昵称、头像、手机号（若使用）

路径：设置 → 服务内容声明 → 用户隐私保护指引

---

## 7. 上线前检查清单

- [ ] AppID / AppSecret 已填入 `backend/.env`
- [ ] 小程序已关联微信支付商户号
- [ ] 服务器域名已备案并配置 HTTPS
- [ ] 隐私协议页面可访问
- [ ] 客服方式已配置（设置 → 客服）
- [ ] 体验版完成至少 3 人内测
- [ ] 商品图片、文案无侵权

---

## 8. 提交审核

1. 微信开发者工具上传代码
2. 公众平台 → 版本管理 → 提交审核
3. 填写功能页面与测试账号
4. 审核通过后点击「发布」

**开发模式**：未申请真实资质前，可使用 `MOCK_WX_LOGIN=true` 和 `POST /api/pay/mock-success` 完成本地全流程演示。
