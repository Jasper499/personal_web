## 兼容性测试

- [ ] iOS 微信最新版
- [ ] Android 微信最新版

## 安全测试

- [ ] 未登录访问受保护接口返回 401
- [ ] 用户 A 无法访问用户 B 的订单
- [ ] 管理接口需 admin token
- [ ] 支付回调验签（生产环境）

## 性能指标

- [ ] 首页首屏 < 2s
- [ ] 商品列表分页加载流畅
- [ ] 图片使用合适尺寸（建议 750px 宽）

## 上线提交材料

提交微信审核时准备：

1. **功能页面路径列表**（见 PRD 页面清单）
2. **测试账号**：管理员账号 + 测试说明
3. **经营资质**：营业执照扫描件
4. **隐私协议 URL** 或页面路径
