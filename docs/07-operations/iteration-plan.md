# 运营与迭代规划

## 数据埋点方案

### 微信官方统计

1. 在 `app.js` 中已接入基础生命周期日志
2. 公众平台 → 统计 → 小程序数据助手 查看 UV/PV

### 自定义埋点事件

| 事件名 | 触发时机 | 用途 |
|--------|----------|------|
| `page_view` | 页面 onShow | 流量分析 |
| `product_view` | 进入商品详情 | 商品热度 |
| `add_to_cart` | 点击加购 | 转化漏斗 |
| `begin_checkout` | 进入结算页 | 下单意向 |
| `purchase` | 支付成功 | GMV 统计 |
| `search` | 执行搜索 | 需求洞察 |

### 接入方式

小程序端调用 `utils/analytics.js` 中的 `track(event, params)`，上报至后端 `/api/analytics/events`（可扩展对接友盟、神策等）。

## 核心指标看板（建议每周查看）

| 指标 | 计算方式 | 健康参考 |
|------|----------|----------|
| DAU | 日活跃用户数 | 持续增长 |
| 转化率 | 下单用户 / UV | ≥ 3% |
| 客单价 | GMV / 订单数 | ≥ ￥68 |
| 加购率 | 加购用户 / 商品浏览 | ≥ 15% |
| 复购率 | 30 天内二次购买用户比 | ≥ 20% |
