# 商业定位文档

## 店铺概况

| 项目 | 内容 |
|------|------|
| 店铺名称 | 匠心小铺 |
| 品类 | 实体零售（日用百货、文创周边） |
| 价格带 | ￥19 - ￥299 |
| 差异化卖点 | 精选好物、同城当日达、到店自提免运费 |

## 目标用户画像

### 主力用户：都市年轻白领（25-35 岁）

- **消费习惯**：习惯微信生态购物，注重颜值与性价比
- **使用场景**：通勤碎片时间浏览、午休下单、周末到店自提
- **痛点**：大平台选择过多难以决策；小店铺缺乏线上下单渠道

### 次要用户：周边社区居民（35-50 岁）

- **消费习惯**：复购率高，偏好熟悉店铺
- **使用场景**：微信分享链接进入、到店扫码下单

## 竞品分析

| 竞品 | 亮点 | 不足 | 可借鉴 |
|------|------|------|--------|
| 美团优选社区店 | 配送快、品类全 | 同质化严重、无品牌感 | 自提点流程 |
| 独立品牌小程序 | 品牌调性强 | 功能复杂、开发成本高 | 首页视觉与分类布局 |
| 有赞微商城模板店 | 上线快 | 模板雷同、月费 | 订单状态流转设计 |

## 盈利模式

1. **商品销售毛利**：主营收入来源
2. **满减促销提升客单价**：满 99 减 10、满 199 减 30
3. **到店自提引流**：自提用户二次到店消费关联商品
4. **第二版会员体系**：储值返利、积分兑换（P1 迭代）

|--------|------|------|
| P0 | 商品展示 + 分类 | 首页、分类页、商品详情 |

| P1 | 到店自提 | 免地址下单 |
| P2 | 优惠券/会员 | 第二版 |
| P2 | 搜索/评价 | 第二版 |

## 关键业务决策

- **销售模式**：线上下单 + 到店自提为主，快递配送为辅
- **配送方式**：同城自提（默认）、快递（满 99 包邮）
- **门店数量**：单店 MVP，数据结构预留多门店扩展
- **营销能力**：第一版不做拼团/直播，仅支持满减展示
