## 高保真视觉要点

- 首页 Banner 使用品牌主色渐变遮罩
- 商品卡片统一 16rpx 圆角 + 轻阴影
- 价格数字使用 DIN 或系统等宽感字体
- 促销标签：黄底黑字 `#F9CA24`
- 空购物车：插画 + 「去逛逛」按钮跳转首页
